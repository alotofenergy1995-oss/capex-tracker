    나만 쓰는 영상 정리 도구

    유튜브 링크를 넣으면 타임라인 노트가 만들어집니다

    Gemini가 영상의 음성과 화면을 직접 보고 구간별로 정리합니다. 자막이 없는 영상도 됩니다.

    1. API 키 넣기설정에 Gemini API 키를 붙여넣습니다. 키는 이 브라우저에만 저장됩니다.
    2. 링크 붙여넣기위 입력칸에 유튜브 주소를 넣고 상세도를 고른 뒤 정리하기를 누릅니다.
    3. 노트 보기타임스탬프를 누르면 그 장면부터 재생됩니다. 스크립트, 질문, 블로그 글은 탭에서 이어서 만듭니다.

    미리 알아둘 것

    • 공개 영상만 정리됩니다. 비공개, 일부 공개 영상은 안 됩니다.
    • 무료 키는 하루 유튜브 영상 8시간까지입니다. 스크립트 만들기와 '영상까지 다시 보고 답하기'도 영상 길이만큼 차감됩니다.
    • 3시간이 넘는 영상은 한 번에 정리하지 못할 수 있습니다.
    • 하이라이트 장면 캡처는 없습니다. 대신 타임스탬프로 그 장면에 바로 이동합니다.

    유튜브에서 열기

    설정

    키는 이 브라우저에만 저장되고 구글 Gemini 서버로만 보내집니다. 키 발급은 aistudio.google.com/apikey 에서 합니다.

    연결 테스트를 하면 이 키로 쓸 수 있는 모델이 목록에 추가됩니다.

    절약 방식은 긴 영상에서 토큰을 크게 줄인다고 안내되어 있지만, 유튜브 링크에서도 되는지는 확인되지 않았습니다. 오류가 나면 기본 방식으로 자동 재시도합니다.
