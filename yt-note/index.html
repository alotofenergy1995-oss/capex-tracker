    나만 쓰는 영상 정리 도구

    유튜브 링크를 넣으면 문서처럼 읽히는 노트가 만들어집니다

    Gemini가 영상의 음성과 화면을 직접 보고 목차, 장면, 근거 시각까지 붙여 정리합니다. 자막이 없는 영상도 됩니다.

    1. API 키 넣기설정에 Gemini API 키를 붙여넣습니다. 키는 이 브라우저에만 저장됩니다.
    2. 링크 붙여넣기위 입력칸에 유튜브 주소를 넣고 길이(짧게·기본·길게)를 고른 뒤 정리하기를 누릅니다.
    3. 노트 읽기[번호]를 누르면 그 장면부터 재생되고 스크립트의 해당 줄이 표시됩니다. 오른쪽 창에서 바로 질문할 수 있습니다.

    미리 알아둘 것

    • 공개 영상만 정리됩니다. 비공개, 일부 공개 영상은 안 됩니다.
    • 무료 키는 하루 유튜브 영상 8시간까지입니다. 스크립트 만들기와 다른 길이로 다시 정리하기도 영상 길이만큼 차감됩니다.
    • 3시간이 넘는 영상은 한 번에 정리하지 못할 수 있습니다.
    • 영상 프레임을 잘라 낸 사진 대신, 장면 설명이 붙은 카드를 누르면 그 부분이 그 자리에서 재생됩니다.

    키는 이 브라우저에만 저장되고 구글 Gemini 서버로만 보내집니다. 키 발급은 aistudio.google.com/apikey 에서 합니다.

    연결 테스트를 하면 이 키로 쓸 수 있는 모델이 목록에 추가됩니다.

    절약 방식은 긴 영상에서 토큰을 크게 줄인다고 안내되어 있지만, 유튜브 링크에서도 되는지는 확인되지 않았습니다. 오류가 나면 기본 방식으로 자동 재시도합니다.

    짧게 버전만 더 가벼운 모델로 빠르게 만듭니다. 기본·길게는 위에서 고른 모델을 씁니다.

    둘 다 긴 영상은 10분씩 나눠 동시에 처리하고, 머리말·핵심 요약은 본문을 바탕으로 깊게 생각해 씁니다. '정확하게'는 차트·슬라이드처럼 화면 글자가 많은 영상에 맞습니다.

    저장 위치: SECOND BRAIN OS › 메모 (영역 · 자원: AI(claude context), 분류: 인포메이션). 중계 스크립트를 구글 Apps Script에 배포한 뒤 그 주소를 넣습니다. 구간별 장면 캡처도 이 중계를 통해 유튜브에서 가져옵니다.
